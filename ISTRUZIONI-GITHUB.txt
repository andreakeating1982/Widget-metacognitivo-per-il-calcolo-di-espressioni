TRASFERIRE SU RENDER (via GitHub):

  1. Crea un repository su github.com (Public o Private).
  2. Carica TUTTI i file di questo pacchetto (root del repo).
     NON caricare: node_modules/, dist/, .git/, .env,
     shared/env.generated.ts.
  3. Vai su render.com -> New -> Blueprint.
  4. Collega il repository: Render legge render.yaml
     e crea il Web Service automaticamente.
  5. Imposta EASY_PEASY_API_KEY in Environment
     (tua chiave personale, mai quella di produzione).
     Il Blueprint installa anche le dipendenze di build
     con --prod=false. Non serve un sito statico.
  6. Controlla la CI. L'autodeploy Render NON attende
     automaticamente l'esito della CI: vedi RENDER.md.

  Dettagli: RENDER.md (runtime Node/Express, NON static site).


COMANDI DI VERIFICA (Node 22):

  corepack enable
  pnpm install --frozen-lockfile --prod=false
  pnpm check
  (cd client && pnpm exec vitest run)   # 738 superati, 28 saltati
  pnpm build
  pnpm start

  Nota: NON esiste uno script `pnpm test`; usare il comando
  Vitest sopra. `pnpm dev` serve solo il frontend (niente /api/*):
  per provare le API usare `pnpm build && pnpm start`.
